# 题型目录与出题规则调研（口算四则 + 数感，一~二年级）

> wayfinder 票 #21 调研结论。调研日期：2026-10-26。
> 目标：为小智设备上的儿童口算练习功能（地图 #20）定义首版题型目录与出题规则。

## 0. 硬约束（地图已定，本文所有规则在此之下）

- **确定性判题**：出题器持有精确答案，ASR 文本归一化后精确比较 → **每题必须有唯一标准答案**（整数或比较符号），排除开放式题。
- **语音作答**：答案必须短（一个整数，或一个比较符号 >、<、=）。
- **文本可渲染**：题目只含文字/数字/运算符，经 `send_display_message` 或 TTS 字幕上屏；看图类、竖式类出局（地图 Out of scope）。
- **不超纲**：以人教版一~二年级教材单元 +《义务教育数学课程标准（2022年版）》第一学段为边界。

## 1. 课标与教材依据（一手/多源交叉）

- 课标第一学段（1~2 年级）「数与运算」学业要求原文：
  > 能描述四则运算的含义，知道减法是加法的逆运算、乘法是加法的简便运算、除法是乘法的逆运算；**能熟练口算 20 以内数的加减法和表内乘除法，能口算简单的百以内数加减法**；能计算两位数和三位数的加减法。
  来源：教育部《义务教育数学课程标准（2022年版）》 http://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582346895190.pdf （正文经网易课标解读、湖南省教育厅转载页交叉验证）。
- 课标入学适应期目标明确"20 以内数的加减法（**不含退位减法**）"——退位减法是入学后正式学习内容，属难点。
- 课标把"简单的整数乘除法"（多位数）放在第二学段（3~4 年级）→ **两位数×一位数不属一~二年级**。

教材单元分布（人教版，目录经电子课本网 dzkbw.com / renjiaoshe.com + B 站官方课程目录 + 文库教材分析多源交叉，旧版 2012 课标版结构多源一致）：

| 内容 | 册·单元 |
|---|---|
| 5 以内认识和加减法（含 0） | 一上① |
| 6~10 的认识和加减法 | 一上② |
| 11~20 各数的认识（含"10 加几、十几加几及相应的减法"） | 一上 |
| 20 以内的进位加法 | 一上末单元 |
| 20 以内的退位减法 | 一下 |

| 100 以内的加法和减法（二）：两位数±两位数（进/退位，竖式为主）、连加连减、加减混合 | 二上 |
| 表内乘法（一）2~6 的口诀 /（二）7~9 的口诀 | 二上 |

注：上表以旧版（2012 课标版）结构为主干（多源一致）；2024 秋起的新版教材单元划分有调整（如新版一下把 100 以内拆成"口算（四）"与"笔算（五）"两单元、各册末增"复习与关联"），但各知识点的册级归属未变，不影响题型分档。数感部分的版本差异见第 4 节前置说明。

**关键发现：「50 以内」在教材中不存在独立单元**——它是口算产品侧创造的 20→100 过渡档（App Store 有独立应用「50以内加减法口算」）。教材的真实过渡层是"两位数±一位数 / ±整十数"（一下）。实现 50 以内档时按"操作数与结果 ≤50"的产品惯例做即可。

## 2. 口算四则：题型目录

通用参数（所有四则题共享）：
- `range`：结果/操作数上限档位（5/10/20/50/100）
- `carry_mode`：进/退位约束（`any` / `no_carry` 不进位 / `carry` 必进位；减法对应 `no_borrow` / `borrow`）
- `missing`：求结果（`a + b = ?`）或求操作数（`a + ? = c`，进阶玩法，答案仍唯一）
- 通用生成规则：**逆推构造法**——减法先随机差 c 与减数 b、被减数 = b + c（天然非负）；除法先随机除数与商、被除数 = 二者之积（天然整除）。避免"随机+校验重试"法的重试开销与边界漏题。（业界两法取舍对比：https://www.cnblogs.com/bxxbb/p/19145107 ；开源参考见第 7 节。）
- 去重：a+b 与 b+a 依交换律视为同题（乘法同理），题内序列按规范化键去重。

### 2.4 除法（表内）

| # | 定义 | 示例 | 参数 | 生成规则 | 答案类型 | 语音适答 |
|---|---|---|---|---|---|---|
| D1 | 表内除法（口诀上限 6） | 36÷6=? | 除数∈[2,6]，商∈[1,9]，被除数=积≤36 档 | **先随机除数 d 与商 q，被除数=d×q**——天然整除、口诀表内、答案唯一 | 整数 | 适合 |

边界决策：
- **除数排除 1**（÷1 无练习价值且口播易与乘法混淆；产品惯例从 ÷2 起）。
- **有余数除法（二下第 6 单元）首版排除**：答案为"商……余数"双整数，语音播报与 ASR 归一化复杂，违背"答案唯一且短"约束。

## 3. 口算难度分层（档位序列）

依据教材编排顺序 + 产品分档惯例（同层内减法难于加法，退位认知负荷高于进位——教材编排与教学经验推断，非课标明文）：

```
5以内 < 10以内 < 20以内不进(退)位 < 20以内进位加/退位减(难点)
  < 50以内(产品过渡档) ≈ 两位数±一位数/整十数 < 两位数±两位数不进(退)位
  < 两位数±两位数进(退)位(口算上限)
表内乘法：口诀≤6 < 全口诀；表内除法同理，且除法因"想乘算除"再难一档
```

同类产品分型参考：
- 「计算题大全」（jisuanti.bmcx.com）一年级细分 39 类（20 以内不进位/进位/退位、整十数、两位数±一位数/整十数各有进退位细分），二年级细分到"6 以内/9 以内口诀与表内乘除"——**与本项目需求最接近的现成分型清单**。
- 小猿口算（小猿AI）按学龄前+1~6 年级、可选运算与位数；作业帮口算覆盖 100 以内加减法等。
- 在线生成器 hldgaofeng.github.io/oralcalc 的分类（进位/不进位、退位/不退位、求结果/求运算项、默认整除）与上文规则一致。

## 4. 数感四类：题型目录

**前置重大发现（影响对标口径）**：2024 秋起一年级启用新课标修订教材，现行新版一~二年级**已无「找规律」独立单元**（旧版 2012 版一下第七单元有；2022 课标把"探索规律"并入"数量关系"主题）。「比大小」「分与合」在新版一上有直接课时，「数的顺序」（相邻数的教材对应物）在一下有课时。找规律仍可保留（市面产品普遍保留，都都数学把 Patterns 列为一级分类），但难度分级按"启蒙/拓展"定位而非"校内同步"。另：「相邻数」不是教材术语，教材叫「数的顺序」。
（新版目录一手来源：dzkbw.com 现行电子课本逐册目录 xs1s_2024 / xs1x_2025 / xs2s_2025 / xs2x_2026。）

### 4.1 比大小

- **定义**：给两个数，在中间填比较符号 >、<、=。校内标准形式即 `9 ○ 6`（"哪个数大"选择题是 App 交互变体）。教材：一上第 2 课时（5 以内，一一对应教具、"开口朝大数"）、一下第三单元课时（100 以内：先比十位、十位同比个位、位数多大）。
- **示例**：`7 ○ 7`、`15 ○ 19`、`38 ○ 45`、`9 ○ 10`（跨十/位数）。
- **参数**：`range`（5/10/20/100）；位数组合（一位○一位 / 两位○两位十位异 / 两位○两位十位同 / 位数不同如 9○10、99○100）；答案目标配比（=、>、< 三种均衡）。
- **生成规则**：按参数随机两数 → 计算答案符号；强制均衡三种答案的配比并**随机交换左右位置**（防"左边大"定势，教辅公认易错点）；可选难度维度"两数差 1 最难"（教辅实践，未从一手教材确认）。
- **答案类型**：比较符号（>、<、=），唯一且极短。
- **语音适答**：适合。ASR 归一化需覆盖"大于/大于号""小于/小于号""等于/等于号/一样/相等"→ 符号。
- 变体：三数排序（"从大到小"）答案长且顺序敏感——**首版不做**。

### 4.2 相邻数

- **定义**：求 X 的前一个数（X−1）或后一个数（X+1）。教材对应「数的顺序」（一下，百数表：横看 +1、竖看 +10）。
- **示例**："16 的后面一个数是几？"→ 17；"19 的后面一个数是几？"→ 20（跨十难点）。
- **参数**：`range`（10/20/100，二下可到万以内——首版不需要）；`side`（front/back）；`step`（进阶：X 前面/后面第 n 个数，n>1）。
- **生成规则**：随机 X∈[1, range−1]（back）或 X∈[1, range]（front）；**排除 0 的前一个数**（不存在）；跨十项（19→20、29→30、20→19）打"高难"标签。
- **答案类型**：单个整数，唯一。
- **语音适答**：适合。**只用单边问法**；双边问法（"与 16 相邻的两个数"）答案是双值有序，拆成连问两题。

### 4.3 找规律

- **定义**：给数列，按规律填空项。模式：等差递增（`3、6、9、12、□`）、等差递减（`20、18、16、14、□`）、交替重复 ABAB（`1、2、1、2、□`）。
- **示例**：`2、4、6、8、□`→10；`10、13、□、□、22、25`（连续中间项，教辅）。
- **参数**：序列长度（4~6 项）；公差 d（1/2/3；d=1 近似数数，d≥2 才是真找规律）；方向（递增易、递减难）；`range`（20/100）；填空位置（末项/中间项/首项）。
- **生成规则**：先随机模式与公差生成完整序列再挖空。**唯一性硬约束：等差序列至少呈现 3 个差值（4 个已知项）、交替序列至少 2 个完整周期**——否则规律不唯一（`2、4、□` 填 6/8/4 都说得通），违反确定性判题前提。首项填空须给出后续至少 3 项。
- **答案类型**：单个整数，唯一（前提如上）。
- **语音适答**：适合；题干朗读数字间需停顿（TTS 播报序列加"、"分隔）。
- 难度排序（末项 < 中间项 < 首项）与"摇摆型"（加减交替）均为教辅/奥数说法，未从一手教材确认——摇摆型首版不做，位置难度作为标签实测校准。

### 4.4 分与合

- **定义**：数的分解与组成。教材：一上第 4 课时「分与合」（2~5），第二单元「6、7 的组成」「8、9 的组成」「10 的认识」。
- **示例**："8 可以分成 3 和几？"→ 5（给部分求部分）；"4 和 5 组成几？"→ 9（求总数）。
- **参数**：总数 range（2~5 → 6~9 → 10）；`ask`（给部分求部分=减法思维较难 / 求总数=加法思维较易）。
- **生成规则**：随机总数 n 与一个部分 p（p∈[1, n−1]，**排除含 0 的分解**；相等对如 4 和 4 保留），另一部分 = n−p，按 `ask` 挖空。**总数=10 加大出题权重**（凑十法直接前置：进位加法"看大数、拆小数"全依赖 10 的组成；10 的标准五对：9和1、8和2、7和3、6和4、5和5）。
- **答案类型**：单个整数（≤10），唯一。
- **语音适答**：适合。
- **禁用形式**：开放式"8 可以分成几和几？"多解，无法确定性判题——只能以填空式出题。

### 4.5 同类产品数感分类横向结论

「口算数感天天练」子类清单未能从一手来源确认（微信小程序不被搜索引擎索引，全网仅一个 SEO 聚合页无题型描述）。已确认的同类产品口径：数感星球（六大训练模式、16 级进阶）、都都数学（Counting / Calculation / **Patterns and geometry** 三主线）、洪恩思维（数感/对比/分类/图形/空间/推理）、小猿/作业帮（按校内题型分类，无数感独立类）。横向结论：国内产品"数感"标签下的内容高度趋同于**数的认识与组成、比较、数序、规律、凑十巧算**五块——与本项目四类吻合；"相邻数"作独立子类主要在幼儿园/幼小衔接产品。

## 5. 通用工程规则汇总

1. **逆推构造**：减法（差+减数→被减数）、除法（除数×商→被除数）从答案侧构造，天然满足非负/整除，无重试。
2. **约束即校验**：档位（≤5/≤10/≤20/≤50/≤100）与进退位开关表达为操作数生成后的一次断言，"把教学边界变成代码能执行、测试能证明的约束"。
3. **去重**：加/乘法交换律同题去重（a+b ≡ b+a）；一次练习内按规范化题面键去重。
4. **答案类型只有两种**：非负整数（0~100）、比较符号（>、<、=）——判题器 ASR 归一化只需处理这两类。

## 6. 剩余不确定点

1. **「口算数感天天练」题型/子类清单未能从一手来源确认**：微信小程序不被搜索引擎索引，无公开介绍页/帮助文档。首版题型以上文教材+同类产品分型为准；若家长可提供小程序内分类页截图，可补齐对标命名。
2. 人教社官网不提供小学数学教材目录，目录依据第三方电子课本站（dzkbw/renjiaoshe）多源交叉；新版教材个别册的单元序号未逐条核实（知识点册级归属不受影响）。
3. 表内除法"除数是否排除 1"无一手明证（本文按产品惯例排除）。
4. 减法难于加法、退位认知负荷更高、找规律填空位置（末/中/首项）难度排序、相邻数"跨十是难点"——均属教材编排+教辅/教学经验推断，非课标或教参明文，建议作为难度标签上线后实测校准。
5. 比大小"两数差距大小"难度维度、"摇摆型"（加减交替）规律题——教辅/奥数实践，未从一手教材来源确认；摇摆型首版不做。
