# 口算练习功能 · 课程答辩演示脚本（约 3 分钟）

> wayfinder #27 结算附件。对应地图 [#20](https://github.com/liyonglion/xiaozhi-esp32-server/issues/20)。

## 前置准备（演示前完成）

- 生产服务器运行中，设备在线，屏幕固件已按 #28 结论确认（题面格式定案：汉字或符号式）
- admin 已登录，设备配置预设「一年级下」（g1b：退位减 + 过渡档 + 相邻数）
- 设备侧预先跑过至少一次完整练习（练习记录页有数据可展示）
- 网络与代理正常；Redis 中无残留会话（演示「全新一轮」）

## 演示流程

**① 家长视角（约 30s）**
1. 打开 admin → 菜单「口算练习」→ 左侧选设备
2. 展示：年级预设下拉（学前~二下）、题型开关、题量 5/10/15/20、讲解开关、自动续轮开关
3. 切到「练习记录」页：指一行记录（时间 / 题型组合 / 答对 X 共 Y / 错题）
> 台词：「家长不需要懂题型，选年级就行，展开才能微调——配置按设备走，一台设备一个孩子。」

**② 孩子视角（约 90s，核心）**
1. 对小智说：「我要练习数学」
   - 预期：TTS 读第一题，屏幕显示 `1/10 43-8=?`（或按 #28 定案的汉字题面）
2. 答对路径：说「三十五」→ ✓ 鼓励语 → 自动下一题
3. 答错路径（第 2 题故意连错两次）：
   - 首错 →「再想想哦」
   - 再错 → 破十法讲解（TTS，题面保持常驻）→ 巩固题一道 → 答对 → 回主流程
> 台词：「判分不是大模型算的——出题器带着精确答案，语音归一化后精确比较；大模型只负责把解法讲成孩子听得懂的话。」

**③ 收尾（约 30s）**
1. 剩余题目快速答完（可提前用 end_practice：说「我不想练了」演示中途退出）
2. 收尾播报：「答对 9 题，共 10 题」+ 按表现生成的鼓励语 → 追问「再来一轮吗？」
3. 答「不用了」结束

**④ 亮点陈述（约 30s，对着评委）**
- 题型目录：人教版一~二年级教材单元 + 2022 课标对齐，逆推构造保证不超纲、天然整除
- 架构：MCP 工具（start_practice / submit_answer / end_practice）+ 服务端会话（Redis 断点续练）+ admin Java/Vue 配置面
- 工程质量：26 题型 × 200 题独立复检断言、确定性判题（LLM 不算数）

## 兜底话术（现场翻车时）

| 意外 | 处理 |
|---|---|
| ASR 把「三十五」识别成别的 | 「语音归一化失败会交给大模型兜底解析」→ 直接再答一次 |
| 屏幕没显示题面 | 「最坏情形设计：TTS 字幕是主通道，题面是补充」→ 继续语音流程 |
| 设备断连 | 顺势演示断点续练：「继续上次的」→ 加分项 |
| 工具调用超时/无响应 | 重说指令一次；仍失败则切亮点陈述 ④ |
| 讲解生成偏慢 | 「讲解是 LLM 即时组织的，数字事实已由工具给定，等的是措辞不是计算」 |
